# plecs-expert-skill

Agent Skills for working with [PLECS](https://www.plexim.com/products/plecs) models:
`.plecs` file grammar, component reference, readable schematic layout, C-Script, and
XML-RPC testing. The skills follow the open [Agent Skills specification](https://agentskills.io/specification),
so they work in Claude, Claude Code, ChatGPT/Codex, Gemini CLI, GitHub Copilot and other
compatible agents.

Status: work in progress (the skill was moved from [pyplecs](https://github.com/tinix84/pyplecs)).
